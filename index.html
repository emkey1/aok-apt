aok-apt

The apt repository of AOK-Workstation: packages for Devuan 6 (excalibur), arm64 and amd64. Today that is pscal, the PSCAL languages and shell.

In AOK-Workstation a native root's companion already has this source:

sudo apt update
sudo apt install pscal
